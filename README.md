# Росток / LOOP 🌱

[**Играть в браузере →**](https://lolkadrish.github.io/rostok-loop/)

Начни с одной грядки и пустого редактора. Напиши `harvest()` и нажми «Запуск», чтобы робот собрал первый урожай. Потом ты сможешь открыть циклы и датчики, посадить новые культуры и расширить поле до 8×8. Код и прогресс сохраняются в твоём браузере.

Игра использует небольшой язык, похожий на Python. Команды и подсказки открываются по ходу десяти глав.

## Локальный запуск

Установи Node.js 20 или новее. Из корня репозитория выполни `npm run dev` и открой http://127.0.0.1:4173. Для проверки игровой логики выполни `npm test`. Устанавливать зависимости не нужно.

Исходники игры и страница для GitHub Pages находятся в `docs/`, тесты — в `tests/`.
