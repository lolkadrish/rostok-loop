# Росток / LOOP 🌱

[**Играть в браузере →**](https://lolkadrish.github.io/rostok-loop/)

Начни с одной грядки и пустого редактора. Напиши `harvest()` и нажми «Запустить», чтобы робот собрал первый урожай. Потом ты сможешь открыть циклы и датчики, посадить новые культуры и расширить поле до 8×8.

Чтобы продолжить на другом устройстве, нажми «Войти» и введи код из письма. Ферма и твоя программа сохраняются в аккаунте. Если играешь гостем, они сохраняются в этом браузере.

Игра использует небольшой язык, похожий на Python. Команды и подсказки открываются по ходу десяти глав.

<details>
<summary>Для разработчиков</summary>

Для работы над исходниками установи Node.js 20 или новее. Из корня репозитория выполни `npm run dev` и открой http://127.0.0.1:4173. Чтобы проверить игровую логику, выполни `npm test`.

Исходники игры находятся в `docs/`, тесты — в `tests/`.

</details>
